## Live compatibility attempt and remaining blocker

medium reasoning, Responses API, 4,096 maximum output tokens, 90-second timeout,
one permitted request per launch and no automatic retries. No research task or
victim episode was sent.

1. The initial implementation did not honor the cloud HTTPS proxy/CA environment;
   it failed with `ConnectError` before any HTTP response. This was a transport setup
   defect, fixed by honoring the environment's existing proxy and certificate trust.
2. After that fix, OpenAI returned **HTTP 401, `invalid_api_key`**. The restored
   checkout has no private `.env`; the inherited `WEBHELIX_API_KEY` did not
   authenticate. The original credential file was not copied, printed or overwritten.

No model reply, candidate, token usage or dollar cost was reported. The check
therefore **did not establish live model compatibility**. A sanitized diagnostic is
in `live-check.json`; provider error prose is intentionally omitted from this small
published example because it may echo credential fragments. Raw local evidence:

- `/workspace/webhelix-runs/adapter-harmless-20261019/`
- `/workspace/webhelix-runs/adapter-harmless-proxy-20261019/`

Restore a usable credential privately, configure its variable explicitly and rerun
`webhelix optimizer check` into a new directory. A passing harmless check would
establish basic editing compatibility only. The earlier research-task service block

## Reproduce and inspect

From a fresh clone of this feature branch:

```bash
bash scripts/setup.sh
uv run --locked pytest -q
uv run --locked webhelix optimizer demo --run-dir "$PWD/runs/adapter-demo-01"
uv run --locked webhelix reservation report \
  --run-dir "$PWD/runs/adapter-demo-01" --output "$PWD/runs/adapter-report-01"
```

In this cloud workspace, dependencies were restored with `uv sync --locked` and
the existing Chromium cache. The exports were
`UV_CACHE_DIR=/workspace/.cache/uv` and
`PLAYWRIGHT_BROWSERS_PATH=/workspace/.cache/ms-playwright`.
Versions: Python 3.12.14, AutoHelix 0.1.1, BrowserGym core 0.14.3, Playwright 1.44.0,
httpx 0.28.1, pytest 9.1.1. No new dependency or lockfile change was required.

The final suite and XML were produced by:

```bash
PLAYWRIGHT_BROWSERS_PATH=/workspace/.cache/ms-playwright \
UV_CACHE_DIR=/workspace/.cache/uv \
uv run --locked pytest -q \
  --junitxml=/workspace/webhelix-research/adapter-final-20261019.xml
```

The completed integration test checks both strict rejections, unchanged retained
files, preserved rejected proposals, exact feedback in request 2 and worktree cleanup.
Other tests cover wrong paths, executable markup, UTF-8 size bounds, no-op replies,
